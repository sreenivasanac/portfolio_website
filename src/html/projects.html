CallEnvoy

Phone-call server for AI agents. Any MCP client (Claude Code, Codex, Claude Desktop, Grok) asks it to call a business; the AI presses the menu keys, waits on hold and talks to the person.

You can listen in and take over at any time. One Python process hosts the MCP endpoint, the telephony webhooks and a voice bot per call.

Voice agents, MCP, Pipecat, FastAPI, Twilio, Deepgram, GPT-4.1

Review Sieve

Search for a business and models read its reviews on Google Maps, Yelp, Tripadvisor and Trustpilot. You get an honest rating, the problems to watch for, and every review tagged genuine, generic, empty or suspicious.

A cheap model tags every review and an expensive one reads only the genuine ones, so a run stays low-cost. The cost is shown before it starts.

LLM pipeline, model cascade, Grok, web data extraction, Python
